# Hex Across-Flats (Wrench Sizes) – Quick Reference

This is a practical table for **wrench flats** sizing when you need a hex collar, nut cavity, or wrench interface.

Note: real hardware varies by standard (ISO vs ANSI), but these are common starting points.

## Metric (common ISO-style)

| Thread size | Across flats (AF) |
|---|---:|
| M3 | 5.5 mm |
| M4 | 7 mm |
| M5 | 8 mm |
| M6 | 10 mm |
| M8 | 13 mm |
| M10 | 17 mm |
| M12 | 19 mm |
| M16 | 24 mm |

## Imperial / SAE (common ANSI-style)

| Nominal size | Across flats (AF) | AF (mm) |
|---|---:|---:|
| 1/4" | 7/16" | 11.11 |
| 5/16" | 1/2" | 12.70 |
| 3/8" | 9/16" | 14.29 |
| 7/16" | 5/8" | 15.88 |
| 1/2" | 3/4" | 19.05 |
| 9/16" | 13/16" | 20.64 |
| 5/8" | 15/16" | 23.81 |
| 3/4" | 1-1/8" | 28.58 |

## CAD modeling tips

- For a **wrench collar**, add a small chamfer on edges for printability.
- For a **nut trap**, add clearance (often 0.2–0.4mm for FDM) and a small lead-in chamfer.
